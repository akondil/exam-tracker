# Contributing

Exam Atlas is a social responsibility project created for the Guidance and Counseling Service at Cumhuriyet Secondary School.

Use Node.js 24 or newer. Run `npm ci`, `npm run check`, `npm test` and `npm run privacy:check`. For desktop changes, run `npm run test:ui` in a graphical session. Keep changes focused and preserve local storage, validation, sandboxing and audit behavior.

Describe the problem, expected result and verification in English. Reproduce parser issues with a generated synthetic PDF; never attach real student records. Extend the synthetic generator when a new layout is needed. Write repository documentation and contribution descriptions in English, while preserving the Turkish application interface, reports and diagnostics.

Do not claim support for a new PDF format until synthetic fixtures and relevant validation tests exist. Test different net-score rules and optional identity fields. Document limitations clearly.
