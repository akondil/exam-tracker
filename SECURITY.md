# Security

Do not publish sensitive student data or credentials in a public issue.

For a vulnerability, use the repository's private vulnerability-reporting feature if the maintainer has enabled it. Otherwise open a minimal issue requesting a private reporting channel, without exploit details or personal records. This project does not provide an invented support address or response-time guarantee.

Include the application version, operating system and a synthetic reproduction. The desktop app uses context isolation, sandboxed renderers, restricted IPC and a local database. Installers are not code-signed. Local SQLite files are not encrypted.
